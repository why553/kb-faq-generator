# 对客答复固定话术（Tone Guide）

本文件收录对客场景的全部固定话术。audience 为 customer 或 both 的问答对，customer_answer 字段必须按本文件规则套用话术生成。话术本身不得改动，中间的事实本体必须逐字来自 answer 字段。

设计原则：先答后礼、不堆客套、不确定的绝不承诺。

## 一、开头话术（按场景选一，不叠加）

| 场景 | 固定话术 |
|---|---|
| 首次咨询 | 您好，关于您咨询的问题，为您解答如下： |
| 追问咨询 | 您好，关于您进一步咨询的问题，为您解答如下： |
| 需分情况说明 | 您好，您的问题需要分以下情况说明： |

## 二、结尾话术（按场景选一，不叠加）

| 场景 | 固定话术 |
|---|---|
| 通用 | 希望以上解答对您有帮助。如有其他疑问，欢迎您随时咨询。 |
| 涉及办理业务 | 如您需要办理相关业务，可携带本人有效身份证件前往就近网点办理，或拨打客服热线咨询。 |
| 涉及动态信息（试点范围、额度等） | 相关业务范围与政策可能动态调整，具体请以最新公告或网点工作人员答复为准。 |

## 三、特殊场景固定话术（触发即必须加，加在事实本体之后、结尾话术之前）

| 触发条件 | 固定话术 |
|---|---|
| 知识库未收录的问题 | 您好，您咨询的问题暂时超出我目前可准确解答的范围。为避免提供不准确的信息，建议您拨打客服热线或前往网点咨询确认。 |
| 时效性内容（needs_review=yes 的条目） | 以上内容可能随政策调整发生变化，请以最新官方公告为准。 |
| 涉及资金安全类问题 | 温馨提示：请妥善保管您的账户信息与验证码，任何工作人员都不会向您索取密码或验证码。如遇可疑情况，请及时拨打官方客服热线核实。 |
| 涉及费用、利率 | 相关收费与利率标准以正式公示为准。 |

## 四、禁用语清单（对客场景一律不得出现）

- 承诺类：稳赚、保本、肯定、绝对、最快、必须成功
- 含糊类：大概吧、应该没问题、差不多。不确定就写以公告为准，不写含糊话
- 命令式：你必须、你赶紧、你去问
- 行内术语：M0、条线、松耦合等术语（对客场景必须换成白话）

## 五、套用公式

```
customer_answer = 开头话术 + answer 原文 + 特殊场景提示（触发时） + 结尾话术
```

组合规则：

1. 开头按场景从第一节选一，结尾按场景从第二节选一，各自只选一条
2. answer 原文逐字放入，不改写、不缩写、不调整语序
3. 特殊场景提示按第三节的触发条件判断，命中就必须加，可叠加多条
4. 生成的 customer_answer 全文不得出现第四节禁用语

## 六、套用示例

原始答案（answer 字段）：计息。自2026年1月1日起，数字人民币实名钱包余额计付利息。

套话术后（customer_answer 字段）：您好，关于您咨询的问题，为您解答如下：自2026年1月1日起，数字人民币实名钱包余额计付利息。以上内容可能随政策调整发生变化，请以最新官方公告为准。希望以上解答对您有帮助，如有其他疑问，欢迎您随时咨询。

## 维护

用户反馈新的对客场景或话术不适用时，把案例追加到本文件对应章节。话术修改需经业务确认后更新，不要只在对话里说明。
